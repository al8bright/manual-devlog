# manual-devlog

AI 세션의 대화 내용과 사용자가 직접 제공한 메모를 바탕으로, **검토 가능한 개발로그 Markdown 초안**을 만들어 주는 Agent Skill입니다. 기본 작성 언어는 한국어이며, 다른 언어를 요청하면 그 언어로 씁니다.

Codex와 Claude Code 양쪽에서 동일하게 동작합니다.

## 무엇을 하나

- 지금 진행 중인 세션의 실제 작업 내용을 근거로 개발로그 초안을 작성합니다.
- 프로젝트 루트(가장 가까운 git 저장소 루트)의 `devlogs/` 폴더에 `YYYYMMDD_[N]_제목.md` 형식으로 저장합니다.
- 같은 날짜에 이미 파일이 있으면 순번을 자동으로 증가시키며, **기존 파일을 덮어쓰지 않습니다.**
- 같은 날 이전 초안을 먼저 읽고 중복을 피합니다. 기존 초안 수정을 요청하면 새 파일 대신 그 파일을 고칩니다.
- 근거가 부족하면 억지로 채우지 않고, 무엇을 기록할지 되묻습니다.
- `devlogs/`를 `.gitignore`에 넣을지 물어봅니다. **기본값은 넣지 않음**이며, 초안은 프로젝트와 함께 커밋됩니다. 사용자가 명시적으로 요청할 때만 `.gitignore`를 수정합니다.

## 무엇을 하지 않나

- 외부에 **발행하지 않습니다.** 업로드 API를 호출하지 않습니다.
- GitHub에서 커밋/이슈를 자동 수집하지 않습니다.
- 저장된 외부 자격 증명을 사용하지 않습니다.
- 근거 없는 작업, 결과, 장애, 수치를 만들어내지 않습니다. 확실하지 않은 내용은 생략하거나 작성자에게 확인할 질문으로 표시합니다.
- 프로젝트명, 비공개 URL, 자격 증명, 고객 정보, 절대 경로, 내부 인프라 정보는 사용자가 명시적으로 허용하기 전까지 문서에 넣지 않습니다.

## 설치

전역 설치(모든 프로젝트에서 사용, Codex와 Claude Code 동시 적용):

```bash
npx skills add al8bright/manual-devlog --skill manual-devlog -g -a codex -a claude-code --copy -y
```

현재 프로젝트에만 설치:

```bash
npx skills add al8bright/manual-devlog --skill manual-devlog
```

옵션 의미는 다음과 같습니다.

| 옵션 | 의미 |
| --- | --- |
| `-g` | 전역 설치 |
| `-a codex` / `-a claude-code` | 설치 대상 에이전트 지정 |
| `--copy` | 심볼릭 링크 대신 파일 복사 (Windows 권장) |
| `-y` | 설치 확인 질문 생략 |

설치 후에는 Codex 또는 Claude Code를 새로 시작해야 스킬이 인식됩니다.

## 사용법

작업을 마친 세션에서 이렇게 요청하면 됩니다.

- "개발로그 작성해줘"
- "수동 개발로그로 정리해줘"
- "오늘 작업 개발로그 초안 만들어줘"

작성이 끝나면 파일 경로, 선택된 순번, 간단한 요약을 알려 주며, 해당 파일이 **로컬 초안이고 발행되지 않았다는 점**을 함께 안내합니다.

## 결과물 형식

```markdown
제목: 제목
태그: 태그1, 태그2,

# 대분류 제목

## 세부 항목

본문 Markdown. 중요한 판단은 **강조**하고, 여러 항목은 목록으로 정리한다.
```

본문에는 근거가 있는 경우에만 아래 섹션을 사용합니다.

- `# 오늘의 목표와 맥락`
- `# 구현한 내용`
- `# 설계와 판단`
- `# 문제와 해결` (실제 문제가 있었던 경우에만)
- `# 검증한 내용`
- `# 다음 단계`

## 수동 설치

`npx skills`를 쓰지 않으려면 `manual-devlog/` 폴더를 스킬 디렉터리에 그대로 복사하면 됩니다.

- Codex: `~/.codex/skills/manual-devlog/`
- Claude Code: `~/.claude/skills/manual-devlog/`

manual-devlog/
